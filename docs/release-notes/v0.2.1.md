# Corrobore v0.2.1

Release date: 2026-06-22

## Highlights

- Enforce signed EE license validation as the only module-gating source.
- Remove legacy license fallback behavior from runtime status surfaces.
- Include domain provider runtime artifacts and manifests directly in the repository under `overrides/domain-providers/` for manual release management.

- Corrobore release publishing is triggered by tag `v0.2.1` via the release workflow.
- Domain provider artifacts currently included:

  - `overrides/domain-providers/v0.1.0-macos-arm64/`
